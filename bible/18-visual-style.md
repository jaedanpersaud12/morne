## Rules

- Each character gets one physical tell that is theirs alone (glasses and the exercise book; the eyebrow nick; the loose earphone; the bandaged wrist; frost on fingertips; the water drum; the key on a cord; the untouched pistol; bare feet and shoots). The tell is what makes them read as different in the same style.
- Nobody is based on a real person. Descriptions come from the cast files, not from anyone the author knows.
- Heritage follows the island's mix (Afro-, Indo-, Chinese-Caribbean). Don't flatten it.
- 16:9 for reference sheets; 3:4 for portrait crops. Regenerate with the same prefix if the aspect changes.
